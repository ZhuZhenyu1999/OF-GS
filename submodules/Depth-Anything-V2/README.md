# Depth Anything V2 (vendored runtime)

This directory provides the depth_anything_v2 Python runtime used by OF-GS. The Apache-2.0 source license is preserved in LICENSE. Demo applications, videos and the separate metric_depth project are omitted.

[Upstream documentation](https://github.com/DepthAnything/Depth-Anything-V2) / [Large model](https://huggingface.co/depth-anything/Depth-Anything-V2-Large)

The default ViT-L/Large model weights are licensed CC-BY-NC-4.0, separately from the source code. Weights are downloaded separately to models/depth_anything_v2_vitl.pth; see the OF-GS usage guide.
