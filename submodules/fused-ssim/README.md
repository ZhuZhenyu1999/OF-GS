# fused-ssim (vendored runtime)

CUDA/PyTorch SSIM implementation used by OF-GS. The MIT license is preserved in LICENSE. Upstream example images and upstream tests are omitted; OF-GS regression tests remain in the repository root tests directory.

[Upstream documentation](https://github.com/rahul-goel/fused-ssim). Install this local copy using the OF-GS usage guide.
